software-design

A plugin for coding agents

Applies A Philosophy of Software Design to the code your agent writes, and flags design problems before the turn ends.

What it does

After every edit, it checks the lines the agent just wrote for the book's red flags and tells the agent while the context is still fresh. Findings in files that change often come first.

● Update(src/editor.ts)
+ insert(text: string, at: number) { this.area.insert(text, at); }

software-design red flag
src/editor.ts:6 pass-through-method
`insert` only forwards its arguments to `this.area.insert`.

The agent fixes it, or keeps it and says why. A suppression without a reason is ignored.

Skills

  • DesignThree competing interfaces, each tested on a reader who has never seen the code.
  • ReviewVerifies the red flags in a diff or branch and reports the five that cost the most.
  • ChangeWeighs the smallest patch against the design the code should have.
  • AuditHotspots, verified findings, and the investments to make first.
  • DocumentComments that say what the code cannot.
  • PerfFaster code without more complexity.

Call one by name, like /software-design:review, or just ask.
